Digital Humanities Resources

A curated collection of tools, tutorials, and datasets for DH research

This resource guide provides links to essential tools, tutorials, and datasets for digital humanities research. Resources are organized by category and regularly updated. Last updated: January 2024.

Text Analysis Tools

Tools for analyzing, mining, and visualizing textual data

Voyant Tools

Web-based tool

User-friendly web application for text analysis. Upload texts and generate word clouds, frequency charts, and concordances without coding.

Free No coding required Web-based

AntConc

Desktop software

Corpus linguistics tool for concordancing and text analysis. Excellent for keyword analysis, collocations, and linguistic patterns.

Free Windows/Mac/Linux

Natural Language Toolkit (NLTK)

Python library

Comprehensive Python library for natural language processing. Includes tools for tokenization, stemming, tagging, parsing, and classification.

Free Python Advanced

Stanford Named Entity Recognizer

Software toolkit

Java-based tool for identifying named entities (people, places, organizations) in text. Pre-trained models available for multiple languages.

Free Java

Mapping & GIS

Tools for spatial analysis and creating historical maps

QGIS

Desktop GIS software

Free and open-source geographic information system. Full-featured alternative to ArcGIS with extensive plugin ecosystem.

Free Open source Windows/Mac/Linux

StoryMapJS

Web-based tool

Create narrative maps that combine location, text, and media. Perfect for telling stories with a geographic component.

Free No coding required

Neatline

Omeka plugin

Geotemporal exhibition builder for creating interactive maps and timelines integrated with digital collections.

Free Requires Omeka

Data Visualization

Tools for creating charts, graphs, and visual representations of data

Tableau Public

Desktop/Web software

Powerful drag-and-drop visualization tool. Free version allows publishing visualizations to the web. Great for exploring data visually.

Free version Interactive

RAWGraphs

Web-based tool

Create custom vector-based visualizations from CSV data. Exports to SVG for further editing in design software.

Free No coding required

D3.js

JavaScript library

Industry-standard JavaScript library for creating custom, interactive data visualizations. Steep learning curve but extremely powerful.

Free JavaScript Advanced

Digital Archives & Collections

Tools for building and managing digital collections

Omeka

Content management system

Web publishing platform for digital collections and exhibitions. Built specifically for cultural heritage institutions and scholars.

Free Open source

Scalar

Publishing platform

Born-digital scholarly publishing platform. Supports non-linear narratives, multimedia integration, and multiple pathways through content.

Free Hosted option

Tropy

Desktop software

Research photo management for organizing and annotating images from archives. Perfect for managing archival photographs and documents.

Free Windows/Mac/Linux

Tutorials & Learning Resources

Guides and courses for learning digital humanities methods

The Programming Historian

Tutorial website

Peer-reviewed tutorials for digital history and humanities methods. Covers Python, R, web scraping, network analysis, and more.

Free Step-by-step Multiple languages

Digital Humanities Research Institute

Course materials

Curriculum and materials from CUNY's intensive DH training program. Covers command line, Python, Git, data analysis, and more.

Free CUNY resource

DHCommons

Project hub

Community platform for DH projects and collaboration. Find project partners, share resources, and discover ongoing DH work.

Free Community

Datasets & Data Sources

Useful datasets for digital humanities research

HathiTrust Digital Library

Digital library

17+ million digitized books and texts. Research access for computational analysis of collections through the HathiTrust Research Center.

Free Large corpus

Library of Congress Digital Collections

Digital archive

Millions of digitized items including photographs, manuscripts, maps, and recordings. APIs available for programmatic access.

Free API available

ICPSR

Data archive

Social science data archive with thousands of datasets covering social, political, and historical topics. CUNY provides access.

CUNY access Social science
