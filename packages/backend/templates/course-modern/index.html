Course Overview

Learn the fundamentals of data science through hands-on projects using Python, pandas, and machine learning libraries. This course covers data collection, cleaning, analysis, visualization, and predictive modeling. No prior programming experience required.

What You'll Learn

  • Python programming for data analysis
  • Data cleaning and preprocessing
  • Statistical analysis and visualization
  • Machine learning basics
  • Real-world data science workflows

Assignments

Weekly Labs

25%

Hands-on coding exercises due each Friday. Complete in Jupyter notebooks and submit via GitHub Classroom. Lowest two scores dropped.

Projects 1-3

30%

Three data analysis projects of increasing complexity. Work individually or in pairs. Each project includes data exploration, analysis, visualization, and a written report.

Final Project

25%

Choose your own dataset and research question. Build a complete data science pipeline from data collection through analysis and modeling. Present findings to the class.
