# Site Studio Development Guide

This guide documents the current local development workflow for the Cloudflare rewrite.

## Dev Servers

Use:

```bash
./dev.sh
```

That starts:

- App Worker on `http://localhost:8792`
- Frontend on `http://localhost:5173`

Logs are written to:

- `app.log`
- `frontend.log`

## Why `dev.sh` Exists

The local setup starts two long-running processes:

- `wrangler dev` for the Worker app
- `vite dev` for the frontend

`dev.sh` tracks their PIDs directly, waits for ports to come up, and shuts them down cleanly on `Ctrl+C`.

## Cleanup

If ports are left occupied, run:

```bash
./scripts/cleanup-ports.sh
```

That cleans:

- port `8792` for the Worker app
- port `5173` for the frontend

## Runtime Shape

### App

- Location: `packages/app/`
- Runtime: Cloudflare Workers + Hono
- Agent: `SiteBuilderAgent` via Durable Objects
- Storage: R2 + KV + Durable Objects

### Frontend

- Location: `packages/frontend/`
- Runtime: SvelteKit + Vite
- Dev proxy targets: `/api`, `/preview`, `/sites` -> `localhost:8792`

## Secrets

Local Worker secrets live in:

- `packages/app/.dev.vars`

Production secrets should be configured in Cloudflare, not committed to the repo.
